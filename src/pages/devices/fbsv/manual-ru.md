## Инструкция

### Режимы работы

Устройство работает в четырёх режимах.

#### Режим ожидания подключения

Как только напряжение на батарее превысит минимальный уровень - устройство включается и переходит в режим ожидания подключения по Bluetooth.
Рекламные пакеты идут с убывающей частотой: первые 30 секунд — каждые 100–150 мс (быстрое переподключение), до второй минуты — каждые 500–600 мс, дальше — раз в 1,28 с. Так прибор быстро находится сразу после включения и почти ничего не тратит, когда его никто не ищет.
В промежутках между рекламными пакетами устройство находится в спящем режиме.

#### Режим внешнего датчика давления

Подключение блютус не требует процедуры связывания. Имя устройства в списке сканирования блютус начинается с `FBSV`.
Как только устройство получает запрос на подключение, активируется периодическое измерение уровня батареи и начинает мигать светодиод.
После установления связи возможно прочитать уровень батареи и подписаться на изменение атмосферного давления.
В последнем случае активируется периодическое считывание данных барометрического датчика с частотой 62 раза в секунду (каждые 16 мс).
Данные фильтруются, сглаживаются и отправляются подписчику 10 раз в секунду.
В промежутках устройство находится в спящем режиме.
При отключении Bluetooth соединения устройство переходит обратно в режим ожидания с периодической передачей рекламных пакетов.

#### Режим звукового вариометра

При нажатии и удержании кнопки устройство играет мелодию и переходит в режим звукового варио. Однократное нажатие кнопки изменяет уровень громкости. Всего их 3.
Повторное нажатие и удержание играет мелодия и устройство переходит в беззвучный режим.

#### Режим транспортировки

Для случая когда уровень заряда еще высокий, но необходимо полностью выключить прибор, например, для транспортировке самолетом.
На задней панели отыскать отверстие под кнопку `Reset`. Нажать один раз и через 2 секунды сразу после того как светодиод моргнет один раз нажать повторно.
Для выхода из режима однократно нажать кнопку `Reset`.

### Питание, зарядка и автономность

Энергию хранит литий-ионный конденсатор на 10 Ф — не аккумулятор. Заряжать его
специально не нужно: солнечная панель покрывает лётный день, а конденсатор
вытягивает переходы в тени и вечер. USB-C нужен на случай, когда прибор
месяцами пролежал в тёмном рюкзаке.

Цифры ниже измерены на приборе ревизии 8 (16.08.2026). Рабочее окно банки — 3,8 → 2,7 В (11 Кл, 3,1 мА·ч); до верхней границы доводит солнце, USB-C поднимает примерно до 3,5 В. Автономности в таблице посчитаны от 3,6 В, то есть это осторожная оценка.

| Режим                                                     | Автономность |
| --------------------------------------------------------- | ------------ |
| Тишина, без Bluetooth, барометр остановлен                | ≈ 52 ч       |
| Звук без телефона, редкое пиканье                         | ≈ 18 ч       |
| Телефон подключён и подписан, звук выключен               | ≈ 10 ч       |
| Телефон подключён, громкость 1, половина времени в наборе | ≈ 8,5 ч      |
| Телефон подключён, громкость 2                            | ≈ 7 ч        |
| Телефон подключён, громкость 3                            | ≈ 5,4 ч      |

Зарядка от солнца с нуля до полного заняла 35 минут на утреннем августовском
солнце под углом; в зенит — около пяти минут. По USB-C всё рабочее окно
набирается меньше чем за минуту, но последние проценты идут заметно медленнее
первых: у верхней границы заряд уже не идёт постоянным током.

Самая дорогая статья расхода — не звук, а опрос барометра: 62 измерения в
секунду стоят около 141 мкА, тогда как первая громкость добавляет 106 мкА.
Поэтому при нулевой громкости и без подключённого телефона датчик
останавливается автоматически — прибор в этом состоянии живёт вдвое дольше.

Заявленная рабочая температура — от −5 °C и выше. Ниже прибор почти наверняка тоже работает: нижняя граница определяется поведением конденсатора, а не электроникой, — но чем холоднее, тем больше работы ложится на солнце.

### Описание протокола связи

Данный раздел предназначен больше для разработчиков чем для обычных пользователей.

Устройство работает по протоколу BLE без сопряжения и авторизации. Изменения каждого параметра доступны по подписке (дескриптор 0x2902). Все нестандартные параметры имеют 128 битный UUID, дискрипторы 0x2901 с текстовым именем параметра и 0x2904 с описанием формата, экспоненты и единицы измерения. Для удобства их значения приведены в таблицах ниже.

Характеристики UUID сервиса `0x181A` ESS

| Name     | UUID   | Size   | Exponent | Unit   |
| -------- | ------ | ------ | -------- | ------ |
| Pressure | 0x2a6d | UINT32 | -1       | Pascal |

Характеристики UUID сервиса `0x180F` BAS

| Name            | UUID                                 | Size  | Exponent | Unit    |
| --------------- | ------------------------------------ | ----- | -------- | ------- |
| Battery level   | 0x2a19                               | UINT8 | 0        | Percent |
| Battery voltage | b0c889e8-16d2-45ef-b615-387f6bca2370 | INT16 | -3       | Volt    |

Характеристики UUID сервиса `0x180A` DevInfo

| Name              | UUID   | Size   | Value     |
| ----------------- | ------ | ------ | --------- |
| Model Number      | 0x2A24 | STRING | FBSV      |
| Manufacturer Name | 0x2A29 | STRING | FlyBeeper |
| Firmware Revision | 0x2A26 | STRING | 0.24      |
