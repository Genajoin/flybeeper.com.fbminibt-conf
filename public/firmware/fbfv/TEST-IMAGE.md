# Тестовый образ для проверки прошивки из браузера

`test-app_update.0.24.1.bin` — сборка для отладки заливки по SMP. Нужна потому, что
залить `0.24.0` поверх `0.24.0` нельзя: тот же образ уже лежит в слоте, и прибор
откажется его помечать.

|                   |                                                                    |
| ----------------- | ------------------------------------------------------------------ |
| Версия            | `0.24.1-0-g8e2b1ae`                                                |
| Размер            | 189 200 байт                                                       |
| sha256            | `4eb530c745e27ad5a70c4323f6323f52b78bfdf12cc2fe9daa04beeb8a203148` |
| Отличие от 0.24.0 | только строка версии — код идентичен коммиту `8e2b1ae`             |

Это тот же код, что в `0.24.0`, собранный под другим номером. Заливать безопасно:
прибор после перезагрузки сообщит в DIS версию `0.24.1`, поведение не изменится.
Чтобы вернуться, залить `app_update.0.24.0.bin` из этого же каталога.

**Имя файла намеренно начинается с `test-`** — тогда оно не совпадает с регуляркой
в `scripts/vite-firmware-index.ts` (`^app_update\.(\d+\.\d+(?:\.\d+)?)\.bin$`), образ не
попадает в `index.json` и не выдаётся пользователям как последняя версия.

Если нужно проверить весь путь через интерфейс (индикатор «есть обновление» → кнопка
«Обновить»), временно переименуйте файл в `app_update.0.24.1.bin`, пересоберите индекс —
и **верните имя обратно перед публикацией**.

sha256 совпадает с тем, что прибор сообщает в состоянии слотов, — по нему и сверяется
результат заливки.

Версия `0.24.1` в общем репозитории прошивки не выпускалась и тега там нет: номер
существует только для этого файла.
